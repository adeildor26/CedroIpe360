# CEDROIPE 360 — EVIDÊNCIAS SUPABASE

Central de documentação do banco de dados.

Registrar:
- Tabelas e colunas
- Relacionamentos e chaves
- Funções SQL e RPC
- Políticas RLS
- Índices
- Triggers
- Migrações

- Integração com n8n
- Histórico de alterações

evitar duplicidades e preservar os dados.
Nunca armazenar credenciais ou dados pessoais.
